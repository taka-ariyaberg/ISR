# ISR

Work from the course *Introduction to Scientific Research* at Uppsala University (2026), group assignment "Anti-stroke Project (Extended)". The project asks whether rapamycin given after an experimental stroke reduces infarct size in aged rats of two strains and both sexes, and how it changes cerebral blood flow.
